# Clash Party v2.0.3 功能对照

本清单用于标记实际交付范围，不能把配置编辑入口等同于上游所有专用编辑器。

| 能力 | 当前实现 |
| --- | --- |
| 控制中心插件、独立 deb | 原生 ModuleInterface 插件、二级功能列表与右侧内容页，按构建环境架构出包 |
| 内核后台运行、关闭窗口继续使用 | dde-mihomo-daemon 管理独立 Mihomo 子进程 |
| 启停、重启、登录自启 | 原生 DSwitchButton 合并启停，失败读回；概览“重启服务”同时重启后台与内核，加载新版本并保留代理模式；启动前验证配置，启动失败恢复最后可用配置，异常退出按时间窗口有限重试，耗尽后还原仍由本插件管理的系统代理 |
| 策略组、手动选择节点、自动组固定选择 | 按订阅展示可折叠代理组、网格节点、完整出口路径；组内独立切换与测速，API 成功后读回状态 |
| 节点搜索、排序、隐藏不可用、延迟测试 | 已实现，支持中文及特殊字符名称 |
| 节点卡片网格、国旗 | 自适应多列、当前节点高亮、SVG 国旗；无法识别地区时显示地球图标 |
| 测速进度、稳定刷新 | Clash Party 默认统一延迟、5000 ms / 50 并发、地址优先级及 Provider 健康检查；卡片转圈，逐节点回收，局部更新 |
| 本地配置、远程订阅、编辑、导出、删除 | 已实现；导入后离线预览节点，无需启动内核或系统代理 |
| URL 直接导入、订阅请求选项 | 可见 URL 输入框、来源显示；支持 User-Agent、Authorization、重定向、超时、代理下载和流量元数据 |
| 订阅自动更新 | 完整候选先校验；相同内容只更新元数据，变化后热加载，保留手动/PAC/关闭状态 |
| 模式、TUN 开关 | 原生开关、Clash 默认参数、DNS 联动、管理员授权、创建状态读回与失败回退 |
| TUN 专用设置 | 协议栈、名称、自动路由/重定向/出口检测、严格路由、MTU、DNS 劫持、CIDR 排除；校验、热加载、唤醒重载 |
| DNS、嗅探、hosts、监听器、隧道 | 常用 DNS/嗅探字段与 Hosts/监听器/隧道表单，保留高级字段及 YAML 编辑；保存前完整校验 |
| 代理端口 | 专用混合/HTTP/SOCKS/重定向/TProxy 表单、运行中应用与失败恢复、系统代理同步 |
| 完整 Mihomo 配置 | 可编辑配置文件与 YAML 覆写 |
| YAML、JavaScript 覆写 | 已实现，JavaScript 在子进程中执行，限时退出 |
| 多覆写排序与按订阅关联 | 本地 YAML/JS 多覆写、启停、排序、关联、保存前后与重复字段预览；远程覆写和市场未实现 |
| 连接查看、搜索、单个/全部关闭 | 已实现；代理链按策略组 → 最终节点展示 |
| 规则查看、搜索、临时禁用、配置编辑 | 网址规则独立持久化、查看/编辑/删除，订阅更新不覆盖；保留高级 YAML 编辑，候选校验失败不落盘；临时禁用需要对应内核 API 支持 |
| 节点/规则资源更新、健康检查、GEO 更新 | 已实现 API 入口；资源轮询局部更新，保留选择与滚动位置；GeoIP/GeoSite/ASN 四类基础数据库随包，首次运行离线准备 |
| 实时流量、内存、连接数 | 固定状态/统计标签，异步增量刷新；未实现长期流量数据库和图表 |
| 日志级别、暂停、清空、导出、后台日志 | 后台历史与实时追加、核心级别同步、断线提示与重连 |
| 系统手动代理、外部 PAC URL | 优先使用 DDE Network DBus，回退现有 gsettings 接口；停止时核实当前设置归属再还原 |
| 自带 PAC 服务、绕过列表专用编辑 | 域名/通配域名/IPv4/IPv6/CIDR 编辑，默认局域网绕过；同步 DDE / gsettings 与动态 PAC，关闭时还原 |
| 本地备份恢复、WebDAV | 完整候选校验、受管文件精确替换、失败回退及恢复前备份；格式与 Clash Party 备份不互通 |
| Gist 同步、Age 加密 | 尚未实现 |
| Sub-Store | 连接已有服务，管理订阅/组合及导入 ClashMeta 转换结果；不内置服务安装或生命周期管理 |
| Smart / Alpha 内核 | 可选用现有二进制；未内置 Smart 模型下载与 AI 覆写 |
| 内核在线升级与版本管理 | 尚未实现，构建脚本固定官方内核版本 |
| 分享订阅格式 | VMess/SSR/HY2/AnyTLS/Trojan/VLESS/SS/TUIC、旧版 SS 与常用 WS/gRPC/H2/HTTP 参数；不支持的传输明确报错 |
| 诊断、残留内核与版本状态 | 只读分层诊断；核实进程身份后明确恢复；界面/后台版本与升级待生效提示 |
| 远程控制器 | 远程 API 操作与本机服务/系统代理管理隔离 |
| 网络信息和 DNS 查询 | DNS 查询已实现；IP 多数据源、SSID 自动切换尚未实现 |
| 机场插件、CPX、二维码导入 | 尚未实现 |
| 托盘、悬浮窗、全局快捷键 | 尚未实现 |
| 多配色、主题市场、自定义托盘图标 | 跟随控制中心主题，原创浅色/深色 SVG；其余尚未实现 |
| Windows/macOS 功能 | 本项目仅面向 Linux 控制中心 |
