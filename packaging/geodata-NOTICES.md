# Bundled official geodata

Unmodified data from MetaCubeX/meta-rules-dat, release commit
`6a7865ed61619c1a6e6d246642018093f556c840`.

Upstream: https://github.com/MetaCubeX/meta-rules-dat
Download URLs, Git blob hashes and SHA-256 checksums are recorded in geodata.json.
The upstream GPL v3 license is provided in geodata.LICENSE.

The upstream project credits Loyalsoldier/geoip, v2fly/domain-list-community,
Loyalsoldier/domain-list-custom and its other upstream data providers.
GeoLite2 ASN data is created by MaxMind, available from https://www.maxmind.com/.
Original generation workflows and source references are available at:
https://github.com/MetaCubeX/meta-rules-dat/tree/master/.github/workflows

Country.mmdb is the upstream country.mmdb file; GeoIP.dat and GeoSite.dat are
geoip.dat and geosite.dat; ASN.mmdb is GeoLite2-ASN.mmdb. Bytes are unchanged.
The runtime does not download these files on first launch.
